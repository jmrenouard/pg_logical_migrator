# Release v1.4.1

## [1.4.1] - 2026-05-07

### Bug Fixes
- **replication**: Fixed a critical bug in `setup-reverse` where the source container failed to resolve the destination host (`pg_target`) by implementing a loopback IP auto-detection mechanism (`inet_server_addr()`) similar to forward replication.

### CI / CD & Packaging
- **ci**: Refactored the GitHub Actions workflow (`python-package.yml`) to execute tests natively on the runner rather than inside a Docker container, fixing DNS name resolution issues (`failed to resolve host 'pg_source'`). 
- **ci**: The CI pipeline now dynamically generates and exports local `MIGRATOR_CONFIG` bridging the Docker test environment (Pagila dataset) with native runner validation.
- **packaging**: Centralized `PYINSTALLER_OPTS` configuration to explicitly adhere to the PyInstaller build requirements enforced in GitHub actions.

### Tests
- **tests**: Containerized the E2E and integration test suites using Docker Compose, establishing an isolated test environment (Runner + Database nodes).
- **tests**: Resolved execution permission blockages (`RESULTS/coverage` root ownership error) emerging from the containerized test runners.
- **tests**: Maintained strict coverage enforcement above 70% while improving test reproducibility across environments.
